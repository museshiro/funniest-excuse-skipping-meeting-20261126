One razor-sharp line that gets you out of a pointless meeting — entered in
[The Funniest Excuse for Skipping a Meeting](https://make.fun/c/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163)
on make.fun.

## The line

> I was in the meeting about whether we need this meeting. We decided we don't.

77 characters — well under the 200-character cap. The joke is recursive: the
only meeting worth attending is the one that votes this meeting out of
existence, which is exactly the verdict every pointless meeting deserves.

A second candidate was drafted and mock-judged against this one before
submission; the winner above is the line `main.ts` writes.

## How it works

`main.ts` writes that single line to `/output/entry.txt` and exits. It makes
no other writes, so it runs fine in a read-only working directory.

Run it with Node 22:

```sh
node main.ts
```
